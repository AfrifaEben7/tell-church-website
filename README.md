# TELL Church

Website for TELL Church in Rapid City, South Dakota.

Requires Node.js 22.12 or newer.

## Local development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

For Cloudflare Pages, use `npm run build` as the build command and `dist` as the output directory.
